Privacy Policy

Empires in the Dust and the "Empires Autopilot" application · Last updated: 31 October 2026

Who we are

This policy covers the Empires in the Dust website and "Empires Autopilot", a private tool operated by the owner of the Empires in the Dust channel to publish the channel's own videos. Contact: h67530241@gmail.com.

Use of YouTube API Services

Empires Autopilot uses YouTube API Services to upload videos to the Empires in the Dust YouTube channel. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the application accesses

  • An OAuth access token for the channel owner's own Google account, granted by the channel owner.
  • The ID of the video it uploads, returned by YouTube after each upload.

The application does not read, collect or store data about viewers, subscribers, commenters or any other YouTube user, and it never accesses any channel other than Empires in the Dust.

How the data is used

The token is used only to upload the channel's own videos, with their title, description and tags, and to set their privacy status. Nothing else.

How the data is stored

The token is stored encrypted on the channel owner's own computer, inside the automation software that performs the uploads. It is not stored on any server operated by us, and it is not sold, shared with or disclosed to any third party.

How to revoke access

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, the stored token stops working.

This website

This website is a static page hosted on GitHub Pages. It sets no cookies and uses no analytics or tracking. GitHub may keep standard server logs (such as IP addresses) for security; see the GitHub Privacy Statement.

Changes
